# Hotel Sales Analysis

## Project Overview

This project analyzes fictional hotel booking and sales data to understand revenue performance, room type performance, booking channels, customer types, monthly trends, and city-level sales.

The analysis was completed using Excel, SQL, Python, and Power BI.

## Dataset

* 500 bookings
* 15 columns
* Fictional hotel booking and sales data
* Customer and booking information
* Room, restaurant, and total revenue data
* Booking dates, stay information, and customer cities

## Tools

* Excel
* MySQL
* Python (Pandas, Matplotlib)
* Power BI
* Git & GitHub
